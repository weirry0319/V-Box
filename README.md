# 图片工具箱 · 使用说明书

> 配套文件：`图片批量工具箱改良版.html`（单文件，双击浏览器打开即可使用，无需安装、无需服务器）

\---

## 一、这是什么

一个纯前端、单文件的多功能图片工作台，把「改尺寸 / 拼图层 / 批量改名 / 参数图排版 / 在线精修」合成一个页面，五个板块一键切换：

|板块|主要用途|
|-|-|
|图片处理|批量改尺寸、转格式、合成顶层图层、批量导出|
|批量重命名|按编号 / 前后缀 / 查找替换规则批量改名，支持撤销|
|详情模板|产品参数图排版（白底图 + 参数表），导出电商详情图|
|主图参数|800×800 主图 + 4 项卖点参数，一键出图|
|在线PS|内嵌 Photopea 完整版在线编辑器（重活精修）|

核心特点：

* **全部本地处理**：图片不经过任何服务器上传（「在线PS」为第三方服务，见第八节）。
* **零安装**：单个 `.html` 文件，拷走就能用。
* **可撤销**：重命名支持「撤销上次」，图片覆盖模式支持「撤销本次覆盖」。
* **记住现场**：上次用的文件夹、顶层图、深色模式、导航栏状态都会记住。

## 二、打开与运行

1. 双击 `图片批量工具箱改良版.html`，或用浏览器拖入打开。

3. **联网情况说明**：

## 四、图片处理

### 4.1 推荐操作流程

1. **导入图片**（M1 顶层图可选，M2 文件夹 / M3 批量文件二选一）
2. 在 **M4 图片列表**点选一张图，在 **M5 实时预览**看效果
3. 在 **M6 处理设置**里设缩放、格式、拼合、导出方式
4. 点 **开始批量处理**，可随时暂停 / 取消
5. 处理完成：**下载 ZIP**（默认），或覆盖模式下结果已写回原文件夹

### 4.2 模块清单

|模块|名称|说明|
|-|-|-|
|M1|顶层PNG图层|可选。上传一张顶层图（PNG/JPEG/WebP，建议带透明通道），处理时叠在产品图上方；支持更换 / 清除；上次用的图会缓存在本地，下次点「恢复定位」可直接取回|
|M2|文件夹导入|拖入或点击选择文件夹，可加多个、自动递归子目录、可追加；状态栏显示「N个文件夹 · M张图片」；支持「恢复上次目录」「清空」|
|M3|批量文件导入|多选图片文件，可多次追加；支持直接拖入 **ZIP**（自动解压并保留目录结构）|
|M4|图片列表|缩略图列表，点击即预览；右上角显示总数，可一键清空；列表滚动加载（每页 100 张，缩略图按需生成，上千张也不卡）|
|M5|实时预览|滚轮缩放预览，双击恢复 100%；与 M4 之间的分隔条可上下拖动调整两块高度，双击复位|
|M6|处理设置|缩放模式、输出格式、图层拼合、导出方式、处理控制（详见 4.3）|
|M7|系统日志台|记录每一步处理结果，可复制 / 清空|

### 4.3 参数说明（M6）

**① 缩放模式**（总开关「启用尺寸调整」，关掉即原尺寸输出）

|模式|用法|
|-|-|
|按像素|指定宽 / 高（默认 1440×1440）；快捷尺寸：800×800、800×1200、1440×1920|
|百分比|按原图比例缩放（默认 50%）|
|最长边|指定最长边像素（默认 1920），短边等比|
|原尺寸|完全不缩放|

勾选「保持宽高比」时按比例适配，不会变形；取消则按填写的宽高拉伸。

**② 输出格式**

* 原格式（默认，图片质量不变）
* PNG / JPEG / WebP：选 JPEG 或 WebP 时出现**质量滑杆**（10–100，默认 90）

**③ 图层拼合（M1 顶层 + 当前图片底层）**

* 顶层缩放：原始 / 宽铺满 / 高铺满 / 拉伸
* 对齐位置：九宫格（左上 … 右下），默认居中
* 偏移微调：X、Y 各 -500 \~ +500 像素（滑杆与数字框联动）
* 不透明度：10–100%

**④ 导出方式**

* **ZIP 打包下载**（默认）：结果打包成 `文件夹名\\\_时间戳.zip` 下载
* **原路径覆盖**：直接写回原文件夹（**仅支持通过「选择文件夹」导入的图片**；处理完仍可再点「下载ZIP」做备份）

**⑤ 处理控制**

* 开始批量处理 → 实时进度条与「已处理/总数」
* 暂停 / 继续、取消（已处理的保留）
* 下载 ZIP
* 撤销（仅覆盖模式有效，把本次覆盖的文件还原为原图）

### 4.4 输出规则与注意事项

* 输出**沿用原文件名与子目录结构**，只按所选格式更换扩展名；ZIP 内同样保持原层级。
* 覆盖模式写回原目录，**会直接替换原文件**；建议先小批量试跑。
* 关闭页面前请先点「下载ZIP」，否则未下载的结果会丢失。
* 覆盖模式必须用「选择文件夹」导入（拖入 / 选择文件拿不到写入权限）。

## 五、批量重命名

### 5.1 推荐操作流程

R1 导入 → R2 设规则 → R3 预览并勾选 → R5 执行 → 在 R4 / R6 看结果与日志

### 5.2 三种导入方式（先看懂这张表）

|导入方式|操作|能否原地改名|说明|
|-|-|-|-|
|选择文件夹|点「选择文件夹…」授权|✅ 可以|处理该目录内全部项，按「目标范围」筛选|
|选择文件|点「选择文件」多选|✅ 可以（需一次授权）|执行时直接在原位置改名，零弹窗（授权后）|
|拖入文件 / 文件夹|拖到虚线框或路径框|❌ 只读，仅预览|浏览器安全限制；可预览，并用「导出改名 ZIP」拿到结果|

> 为什么拖入不能改名：浏览器不允许脚本直接改磁盘文件名，必须通过授权过的「文件夹句柄」写回。首次用「选择文件」时，把文件所在文件夹拖入授权一次即可，之后不再弹窗。

### 5.3 三种命名规则

**① 编号命名**

|参数|说明|
|-|-|
|前缀 / 后缀|拼接在序号前后，例：前缀「主图\_」+ 后缀「\_800」|
|起始编号|默认 1|
|编号位数|补零位数，3 → 001|
|快捷前缀|主图 / 详情页 / sku / 视频 / 白底图，点一下自动填入|

示例：前缀「主图\_」、起始 1、位数 3、保留扩展名 → `主图\\\_001.jpg`、`主图\\\_002.jpg`…

**② 原名加前后缀**

示例：`logo.png` → 前加「主图\_」、后加「\_800」→ `主图\\\_logo\\\_800.png`

**③ 查找替换 / 删除**

* 查找内容 → 替换为；「替换为」留空即**删除**
* 可勾选「区分大小写」
* 示例：查找「-」替换为空 → `文件-01.jpg` → `文件01.jpg`

### 5.4 通用选项

|选项|作用|
|-|-|
|文件和文件夹 / 仅文件 / 仅文件夹|控制参与改名的对象范围|
|保留原扩展名|勾选时扩展名不参与改名（推荐）|
|排序依据|名称 A→Z、名称 Z→A、修改时间 新→旧、修改时间 旧→新；编号按此顺序分配|

### 5.5 预览区（R3）怎么读

* **左右双栏各占一半**：左边原文件名、右边新文件名，表头固定；两栏**垂直滚动同步**、**水平滚动各自独立**（互不干扰）。
* **行联动**：鼠标停在任意一行，左右同一行同时高亮。
* **勾选**：左侧每行有复选框，默认全选；表头复选框可全选 / 全不选，右上显示「已选 N/M」。
* **红色行 = 会被跳过**：目标文件已存在 / 批次内重名 / 文件名超过 255 字符。红色行复选框禁用，鼠标悬停在「新文件名」那行可看到具体原因。
* **只有「新文件名」一侧标红**，原文件名永不标红（原文件本来就是合法的）。
* **表头汇总**：「新文件名」右侧显示「（N 项超过255字符）」，因此每一行不再重复写提示文字。
* **非法字符**：`\\\\ / : \\\* ? " < > |` 无法用于文件名，输入后会自动替换为下划线，并在输入框右侧红字提示；前缀、后缀任一含非法字符都会提示，两者都合法才消失。

### 5.6 执行、撤销与快捷键

* **执行重命名**：只处理已勾选项；冲突项自动跳过；日志给出「成功 / 跳过 / 失败」数量。
* **撤销上次**：回滚最近一次执行（需对应文件夹授权仍有效）。
* **导出改名 ZIP**：只在「只读导入（拖入）」时出现，把勾选项按新名字打包下载。
* **快捷键**（光标不在输入框时生效）：

|按键|功能|
|-|-|
|Enter|执行重命名|
|Backspace|撤销上次|
|/ （或 \\、、）|刷新预览|

### 5.7 常见提示怎么处理

|现象 / 提示|原因与处理|
|-|-|
|「该文件未授权…」|把文件所在文件夹拖入虚线框授权一次，或改用「选择文件夹」|
|「目标文件已存在或无法修改」|有同名文件；调整规则，或先清理同名文件|
|新名变红且提示「文件名过长」|电脑单文件名上限 255 字符（含扩展名），请缩短前缀 / 后缀|
|输入长文本稍慢|预览已做 150ms 防抖，停止输入后自动刷新；输入过程中不重复渲染|

## 六、详情模板（产品参数图）

用于快速做电商「产品参数」详情图。

1. **白底图**：点「上传白底图」选择产品图；显示方式可选「完整显示（推荐）」或「铺满裁剪」；预览区滚轮可缩放白底图，双击恢复 100%；可「清除」重来。
2. **背景层**：用取色器自定义背景色；「取图色」会自动识别上传图片的背景色并套用；「重置」恢复纯白。
3. **参数内容**：

   * 每行左侧「⠿」是拖拽手柄，按住可上下调整该行顺序；
   * 参数名可直接点开修改（回车确认），画布左侧同步变化；
   * 内容是文本框，可多行输入；右侧圆形按钮可一键清空该行内容（不改标签）；
   * 点「添加一行参数」新增行，新增行右上角有删除按钮（默认行不可删，避免误删模板结构）；
   * 材质、尺寸等行下方有常用词芯片，点选可快速组合写入；
   * 「保养」行为固定说明行，面板中不显示，避免误改；
   * 「词条分隔符」支持 `斜杠 /`（推荐）或空格。
4. **表格高度自适应**（默认开）：行数变多时画布按比例增高，不被固定高度截断，行距保持宽松。
5. **导出设置**：

|项目|可选项|
|-|-|
|尺寸|1440×1920（默认，模板原比例）、750×1251、1080×1440、1080×1920、1242×2208、自定义|
|格式|JPG（100% 画质）/ PNG（无损）/ WebP|
|画质|50%–100% 滑杆|

导出文件名：`产品参数图\\\_宽x高.扩展名`。

> 布局基准为 750×1251（左右边距 36、卡片顶 650、首行 719.5、行距 53.3、底部 36），换尺寸时整体等比缩放。

## 十、常见问题（FAQ）

**Q1：为什么拖进来的文件点「执行重命名」没反应？**
A：拖入属于只读导入，浏览器不允许改名。改用「选择文件夹」或「选择文件」导入；若只想拿到结果，用「导出改名 ZIP」。

**Q2：红色行会被改名吗？**
A：不会，执行时自动跳过。红名原因：目标已存在、批次内重名、文件名超过 255 字符。

**Q3：原文件名没超长，为什么也标红？**
A：已修正——现在只有「新文件名」一侧标红；左侧原文件名保持正常颜色，方便对照。

**Q4：改错了能撤回吗？**
A：重命名点「撤销上次」可整体回滚；图片处理的覆盖模式点「撤销」可还原本次覆盖的原图。撤销依赖原文件夹授权仍然有效。

**Q5：断网能用吗？**
A：图片处理、改名、详情模板、主图参数都可用；ZIP 导出/导入和「在线PS」需要网络。

**Q6：会破坏原图吗？**
A：默认 ZIP 导出，原图不动。只有主动选择「原路径覆盖」时才会替换原文件，且该模式可撤销。

**Q7：支持 Safari / Firefox 吗？**
A：可以打开并预览，但「文件夹授权写回」能力支持有限，会退化成只读模式（用「导出改名 ZIP」交付结果）。建议用 Chrome / Edge。

**Q8：图片很多会不会卡？**
A：列表分页渲染（每页 100 张）、缩略图按需生成、批量处理并发 8 张。建议单批控制在几百张，超大图先缩小再处理。

## 十一、兼容性与已知限制

* 单文件 HTML；ZIP 相关功能依赖 CDN 上的 JSZip，在线PS 依赖 Photopea，其余功能完全离线。
* 浏览器「文件系统」授权按站点保存，换目录、换浏览器需重新授权。
* 文件名长度上限 255 字符（含扩展名），超出会在预览中标红跳过。
* 覆盖模式属高风险操作，建议先拿一个副本文件夹试跑。
